Deliberate non-features

Things this mock refuses to imply.

No stored org chart

“Executive → worker” is a derived attention view over tasks, grants, profiles, messages, and proposals. There is no hidden manager rank.

No transcript-as-memory

The executive identity is durable even when its provider run is replaced. Canonical continuity comes from packets, messages, proposals, knowledge, and receipts.

No invented telemetry

No confidence score, percentage progress, speculative cost, hidden “thinking,” or role-derived authority is rendered.

No browser authority

The browser never reads SQLite, provider homes, capability files, MCP sockets, runtime handles, or Git directly.

No terminal-as-record

Herdr hosts interactive terminal capability. Canonical state stays in the daemon; raw PTY output is diagnostic.

No fake execution

Every button in this static file reports the exact method it would invoke and explicitly leaves state unchanged.
